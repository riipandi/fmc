# fmc documentation

Start with the first page if you have never run fmc. Each page is for one job, so you can jump to the one you need.

- [Install](install.md): for anyone who has not installed fmc. Answers how to get it with Homebrew, from the release archive, or from source, and which font and terminal it needs.
- [Usage](usage.md): for a first session. Answers what each screen does: opening a folder, the panes, the preview, Markdown, the changes screen, git signs, the finder, copying, and the narrow layouts.
- [Keys](keymaps.md): for looking up a key or a mouse action while you work. Every key fmc reads, grouped by screen.
- [Configuration](configuration.md): for changing how fmc behaves. Answers which keys the settings file takes, what each one does, and how file associations and the finder's matching work.
- [Command line](cli.md): for scripting or for an error message. Answers which arguments fmc takes, what `--help` and `--version` print, and why a run stops.
- [Differences from Scouter](parity.md): for Scouter users. Answers where fmc behaves differently from Scouter v0.3.4, and why.
- [Development](development.md): for people who build or change fmc. Answers how to build it, which checks to run, and how a release is cut.

The product's purpose and principles are in `PRODUCT.md`, and the palettes, layout, and components are in `DESIGN.md`, both at the repository root.
